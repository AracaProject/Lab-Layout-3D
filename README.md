# Lab layout 3D

Interactive 3D model of the lab for planning equipment placement. Drag equipment around; it turns red when it collides and shows the maximum height of each free space.

Open `index.html` in a browser, or publish with GitHub Pages. No server, build step or sign-in needed.

- Layouts are saved in each visitor's own browser.
- **Copy share link** puts the whole layout inside the link. Anyone who opens it gets their own copy to edit.
- Dimensions are in cm. Socket heights, tap height and the 232 cm ceiling are estimates.

Three.js r128 (MIT licence) is included inside index.html.
